
## How to Customize

### 📸 Add Photos

**Memory Slideshow** (4 slots in index.html):
Replace `photo1.jpg`, `photo2.jpg`, `photo3.jpg`, `photo4.jpg`
with your actual image files placed in the same folder.

**Final Screen — Couple Photos**:
Replace `sasi.jpg` and `thanuja.jpg` with the actual photos.

### 🎵 Add Music (Optional)
Place two `.mp3` files in the same folder:
- `opening.mp3` — soft background music (plays during opening + proposal)
- `yes.mp3` — cheerful romantic music (plays after YES click)

If no audio files found, everything still works silently.

### ✏️ Edit Captions
Open `index.html` and edit the `.slide-caption` text inside each `.slide` div.

## 🚀 Deploy to GitHub Pages

1. Create a new GitHub repo
2. Upload all files to the repo root
3. Go to Settings → Pages → Deploy from branch (main / root)
4. Your URL: `https://yourusername.github.io/reponame`

## 🚀 Deploy to Vercel

1. Install Vercel CLI: `npm i -g vercel`
2. Run `vercel` inside the project folder
3. Follow prompts — done!
